# 第 10 节 · 团队绩效域
> 学完日 2026-08-03 / 掌握度 中高（5题3/5+变式2/2，错服务型领导力/塔克曼阶段退回）/ 关联错题：05-mistakes/people.md

## 定位
8 绩效域第二个（"干团…"的"团"）。团队绩效域 = 与负责生成项目可交付物以实现商业成果相关的人员活动和功能。核心使命：**创建文化和环境，让个体集合演变成高绩效团队**。PMBOK7 §2.2。

## 预期成果（3 条）
1. 共享责任
2. 高绩效团队
3. 所有成员展现领导力 + 人际关系技能

## 关键定义
- **项目经理**：执行组织委派，领导团队实现目标
- **项目管理团队**：直接参与 PM 活动的成员
- **项目团队**：执行项目工作、实现目标的一组人员

## 管理与领导力（§2.2.1）
| | 聚焦 | 内容 |
|---|---|---|
| 管理活动 | 手段 | 程序/规划/协调/测量/监督 |
| 领导力活动 | 人 | 影响/激励/倾听/促使 |

- 领导力应由**所有成员**实践；管理可集中可分布
- 集中式：担责给某个人（如 PM），项目章程授权
- 分布式：自组织，无指定 PM，引导者角色轮流

### 服务型领导力（Servant leadership，核心）
- 聚焦**了解并满足成员需要及发展**，促成最高团队绩效
- 3 自问：成员是否在成长？更健康/明智/自由/自主？更可能成为服务型领导者？
- 3 行为：**消除障碍**（关键角色，最大化价值交付）/ 避免分心 / 鼓励和发展机会

## 团队发展（§2.2.1.3 + 第 4 章模型）

### 共同方面 5 项
愿景和目标 / 角色和职责（识别技能差距，培训辅导教练）/ 项目团队运作（**团队章程 + 规范**）/ 指导 / 成长

### 塔克曼 5 阶段（高频，可退回）
| 阶段 | 特征 |
|---|---|
| 形成期 Forming | 刚组建，礼貌客气，角色不确定 |
| 震荡期 Storming | 冲突、分歧、争论 |
| 规范期 Norming | 调整工作习惯配合、形成规范、凝聚力增强 |
| 成熟期 Performing | 高绩效、信任、自组织 |
| 解散期 Adjourning | 项目结束 |

**关键**：阶段非单向，信任不足/新成员加入可**退回**前一阶段。

## 项目团队文化（§2.2.2）
- 文化可有意识（规范）或非正式（行为）形成
- 偏见公开透明对待 -> 建立信任
- PM 是形成安全、尊重、无偏见环境的关键
- 期望行为典范 7 项：透明 / 诚信（含及早发坏消息）/ 尊重 / **积极的讨论（对话 ≠ 辩论：对话=共识，辩论=赢输）** / 支持 / 勇气（实验文化）/ **庆祝成功（实时认可）**

## 高绩效项目团队 9 因素（§2.2.3）
开诚布公沟通（基石）/ 共识 / 共享责任 / 信任 / 协作 / 适应性 / 韧性 / 赋能 / 认可

## 领导力技能（§2.2.4）
- **愿景**：回答 4 问（目的/成功定义/未来更好/如何知偏离）；清晰简明可行
- **批判性思维**：理性逻辑证据；识别偏见/根因；归纳/演绎/溯因 + 元认知
- **激励**：内在（成就/挑战/自主/成长/相互关系…）vs 外在（奖金）；按首要因素裁剪
- **人际关系技能**：
  - **情商 4 领域**：自我意识 / 自我管理 / 社交意识 / 社交技能（某些模型加第 5：动机）；情商是领导力基础
  - **决策**：单方面 vs 群体；**发散/汇聚模式**；罗马式表决/宽带德尔菲/举手表决；超权则升级
  - **冲突管理**：4 方法（开诚布公+尊重/聚焦问题不针对人/聚焦当前未来/一起找备选）；**5 mode**

### 冲突解决 5 mode（高频）
| mode | 含义 | 适用 |
|---|---|---|
| 面对/解决 | 合作共赢 | 最优，时间允许 |
| 妥协/调解 | 各让一步 | 双方都让 |
| 缓和/包容 | 强调一致、让步 | 关系优先、分歧次要 |
| 强制/命令 | 权力强加、牺牲他人 | 紧急/原则问题 |
| 撤退/回避 | 逃避、拖延 | 微不足道/时机不对 |

## 裁剪领导风格（§2.2.5）
变量：特定项目经验 / 团队成员成熟度 / 组织治理结构 / 分布式项目团队（技术增加沟通，**至少一次面对面**建关系）

## 检查结果（表 2-3）
| 成果 | 检查 |
|---|---|
| 共享责任 | 了解愿景目标；对可交付物和成果担责 |
| 高绩效团队 | 信任协作；适应+韧性；赋能+认可 |
| 领导力+人际关系技能 | 运用批判性思维和人际关系技能；风格适合背景 |

## 易混 / 易错
- **服务型领导力**本质 = 了解并满足成员个人需要（不是只点名"服务型领导"再上团建）；做题：**描述具体行动 > 只点概念名称**
- **塔克曼**："调整工作习惯配合/形成规范/凝聚力增强" = **规范期**（非震荡）；阶段**可退回**（信任不足/新成员 -> 退回震荡）
- **对话 ≠ 辩论**（共识 vs 赢输）
- **激励**：项目工作多与**内在**激励一致；按首要因素裁剪
- **情商 4 领域**：自我意识/自我管理/社交意识/社交技能
- **冲突 5 mode**：移除/强令 = 强制；逃避 = 撤退；各让 = 妥协；找共赢 = 面对
