# 第 9 节 · 干系人绩效域
> 学完日 2026-08-03 / 掌握度 高（5/5 全对）/ 关联错题：无（本节全对）

## 定位
8 绩效域第一个（"干团开规项交测不"的"干"）。干系人绩效域 = 与干系人相关的活动和功能，渗透所有绩效域。PMBOK7 §2.1。

## 预期成果（3 条，检查结果表对应）
1. 整个项目期间与干系人建立**富有成效的工作关系**
2. 干系人对项目**目标表示同意**
3. **受益人支持并满意**；可能反对的干系人**不产生负面影响**

## 关键定义
- **干系人**：影响项目、或会受 / **自认为会受**项目影响的个人、群体、组织（"自认为"也算）
- **干系人分析**：系统收集定量+定性信息，确定该考虑谁的利益

## 核心：干系人参与 5 步骤（图 2-3）
**识别 -> 理解和分析 -> 优先级排序 -> 参与 -> 监督**

### ① 识别
- 组建团队前可做高层级识别；详细识别**渐进明细化**，**贯穿全程**
- 易识别（客户/发起人/团队/最终用户）vs 难识别（无直接联系者）

### ② 理解和分析
- 了解干系人的感受/情绪/信念/价值观（会变，持续动作）
- 分析维度：**权力 / 作用 / 态度 / 信念 / 期望 / 影响程度 / 与项目的邻近性 / 在项目中的利益**
- 考虑干系人之间互动与**联盟**（助力或阻碍）
- **分析结果保密**，超出分析背景去用会引发误解

### ③ 优先级排序
- 干系人太多无法全部有效参与 -> **聚焦权力和利益最大的**
- 随事件变化重新排序
- **权力/利益方格**（4 象限 4 策略）：

  | 象限 | 策略 | 典型角色（助记） |
  |---|---|---|
  | 高权 + 高利 | 重点管理 | 发起人、高层赞助者 |
  | 高权 + 低利 | 令其满意 | 监管机构、政府部门 |
  | 低权 + 高利 | 随时告知 | 最终用户、业务团队 |
  | 低权 + 低利 | 监督 | 外围公众 |

### ④ 参与
- 协作：介绍项目 / 启发需求 / 管理期望 / 解决问题 / 谈判 / 优先级排序 / 处理难题 / 决策
- **软技能**（积极倾听、人际关系、冲突管理）+ **领导技能**（创建愿景、批判性思维）
- **沟通类型（表 2-1，正式×口头/书面 四象限）**：
  - 正式+口头：演示、项目审查会议、情况介绍、产品演示、头脑风暴
  - 正式+书面：进展报告、项目文件、商业论证
  - 非正式+口头：对话、特别讨论
  - 非正式+书面：便条、邮件、即时消息、社交媒体
- **沟通方法（推/拉/交互，高频考点）**：

  | 方法 | 特征 | 示例 |
  |---|---|---|
  | 推式 | 单向推送，妨碍立即反馈，**慎用** | 备忘录、邮件、状态报告、绩效报告、语音邮件 |
  | 拉式 | 干系人**主动来取**，可间接察觉顾虑 | 内部网、知识库、在线存储库、公开网页 |
  | 交互式 | 双向交换，**参与最深**，带快速反馈循环 | 对话、电话、会议、头脑风暴、产品演示 |

  - **参与比推/拉都深**，参与本身就是交互式沟通

### ⑤ 监督
- 干系人会变：新识别、退出、态度/权力变化
- 评估当前参与策略是否有效、是否调整
- 满意度衡量：对话 / 迭代审查会 / 产品审查会 / 阶段关口 / 问卷（量大时）
- 必要时**更新干系人参与方法**提高满意度

## 与其他绩效域相互作用
干系人**渗透项目各方面**：定义并排序需求/范围、参与规划、确定验收与质量标准、使用可交付物、影响项目成果；有些**减少**不确定性、有些**增加**不确定性。

## 检查结果（表 2-2，成果 ↔ 检查方法）
| 成果 | 检查方法 |
|---|---|
| 富有成效的工作关系 | 观察；参与连续变化反映满意相对程度 |
| 干系人同意项目目标 | 范围外需求大量变更/修改 = 没参与进来、与目标不一致 |
| 受益人支持满意 / 反对者无负面影响 | 行为表明满意/支持还是反对；调研、访谈、焦点小组；审查**问题日志和风险登记册**识别单个干系人挑战 |

## 易混 / 易错
- **沟通方法三分类**：推=单向（报告/邮件群发）、拉=自取（网页/知识库）、交互=双向（会议/对话）且参与最深
- **权力/利益方格**：高权低利=**令其满意**（不是监督）；低权高利=随时告知；低权低利才=监督
- **参与度评估**：当前 < 所需 -> **分析原因 + 制定方案消除差距**（不降低标准、不直接要求、不放任）
- **识别持续性**：识别贯穿全程；识别到即登记，即使当前影响小也要登记并关注（影响会变）
- 干系人定义含"**自认为**"受影响者
