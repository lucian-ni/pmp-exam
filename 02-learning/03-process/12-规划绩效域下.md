## 一、质量规划（§2.4.8 度量指标 + §2.4.9 一致性 + 原则8）

### 原则8：将质量融入过程和可交付物
- 质量非最后检查，融入规划/过程。从规划阶段就定质量标准、度量、测试方法，让过程本身适当有效。
- 考法：题干"后期才发现缺陷、验收大量返工"-> 缺早期质量融入，选"规划时定义质量标准和度量/测试方法"。

### §2.4.8 度量指标
- 设定**临界值**三态：符合预期 / 有偏离趋势（正/负向）/ 不可接受
- **"只测量重要的东西"**（高频考点句）
- 度量分层：与**产品**相关度量仅适用于**正在开发的可交付物**；与**进度/预算**相关度量由**组织标准**驱动、与**基准**比较

### §2.4.9 一致性
范围和质量要求的绩效规划与以下 **5 方**保持一致：
> 交付承诺 / 分配的资金 / 资源的类型和可用性 / 项目固有的不确定性 / 干系人的需要
- 测试计划与质量和交付需求一致
- 大项目合并到整合的项目管理计划；小项目详细计划反低效（规划工作量适当，呼应节11）

### 口诀
**融入非检查 · 只测重要 · 临界三态 · 一致五方**

## 二、资源规划（§2.4.3 团队 + §2.4.5 实物资源）

### §2.4.3 项目团队组成和结构
- 确定技能组合，评估 **3 维度**（非仅技能）：技能 + 熟练程度 + 类似项目经验年限
- **内部 vs 外部**：成本结构不同，PM **权衡**外部技能收益 vs 成本（非"外部一定更好/更贵"）
- **同地点 vs 分布式**：
  - 同地点小型团队 = **渗透式沟通** + 问题出现即解决（高效）
  - 分布式（不同城市/时区/国家）= 需**更多时间通过技术手段连接**（成本）

### §2.4.5 实物资源
- 人员以外任何资源：材料/设备/软件/测试环境/许可证
- 规划 **4 要素**：估算 + 供应链 + 物流 + 管理
- **提前期**：材料 交付/移动/存储/处置 全周期
- 跟踪材料库存（抵达现场到集成交付）
- 权衡：批量订购 vs 存储成本 / 全球物流 / 可持续性 / 实物资产整合
- 考法：建筑项目"材料断供致延误"-> 缺实物资源提前期/供应链计划

### 口诀
**人三评（技能·熟练·经验）/ 内外权衡 / 同地渗透·分布费时 · 物四要（估算·供应链·物流·管理）/ 提前期全程**

## 三、沟通规划（§2.4.4 沟通）

### 定位（与节9区分）
- §2.4.4 明确**与干系人绩效域（§2.1，节9）重叠**
- **节9**=沟通本身（类型表2-1 正式/非正式×口头/书面；方法推式/拉式/交互式）
- **节12**=沟通的"规划"（制定沟通过程和计划）--"用什么沟通" vs "怎么规划沟通"

### 核心论断
> **沟通是争取干系人有效参与最重要的因素。**

### 规划 6 要素（高频考点）
谁需要信息 / 每个干系人需要哪些信息 / 为什么共享 / 最佳方式 / 何时多久一次 / 谁拥有信息
口诀：**谁·什么·为什么·方式·何时·谁拥有**

### 信息类别三分
- 内部 vs 外部
- 敏感 vs 公开
- 一般 vs 详细

分析 **干系人 + 信息需求 + 信息类别** -> 制定沟通过程和计划。

## 12a 易混 / 易错
- **质量融入 vs 最后检查**（原则8）
- **"只测量重要的东西"**
- **临界值三态**：符合预期 / 偏离趋势 / 不可接受
- **质量一致 5 方**：交付承诺 / 资金 / 资源 / 不确定性 / 干系人需要
- **团队技能评估 3 维度**：技能 + 熟练 + 经验年限（非仅技能）
- **同地点=渗透式沟通；分布式=技术连接额外时间成本**
- **实物资源 4 要素**：估算 + 供应链 + 物流 + 管理（含提前期 交付/移动/存储/处置）
- **沟通 6 要素**：谁/什么/为什么/方式/何时/谁拥有
- **沟通规划 vs 沟通类型/方法**：节12规划 / 节9 用什么
- **沟通是争取干系人有效参与最重要因素**

## 四、风险应对规划（§2.8.5，节 16 完整讲，此处建策略框架）
> 风险主体在不确定性绩效域 §2.8（节16）；规划绩效域 §2.4.10 只点"规划与不确定性相互作用"。本节讲规划阶段要定的应对策略。

### 威胁 5 策略（§2.8.5.1）
| 策略 | 核心 | 典型动作 |
|---|---|---|
| 规避 | 消除威胁或保护项目免受影响 | 改需求/改方案/砍风险源 |
| 上报 | 不在项目范围/超 PM 权限 | 报发起人，责任转移 |
| 转移 | 应对责任转第三方担责 | 保险、固定价外包 |
| 减轻 | 降概率和/或影响 | 加测试、备冗余、原型 |
| 接受 | 承认不主动规划 | 主动=应急计划；被动=不做 |

### 机会 5 策略（§2.8.5.2）--与威胁配对
| 策略 | 核心 | 对应威胁 |
|---|---|---|
| 开拓 | 确保机会出现 | ↔规避 |
| 分享 | 责任分给最能获益第三方 | ↔转移 |
| 提高 | 提概率/扩影响 | ↔减轻 |
| 接受 | 承认不主动 | ↔接受 |
| 上报 | 超权限/不在范围 | ↔上报 |

### 次生 vs 残余风险（高频易混）
- 次生风险=应对措施本身产生的新风险
- 残余风险=应对后仍将存在的风险
- 应对规划反复进行，直至残余风险与组织风险偏好相符

### EMV vs ROI
- EMV（预期货币价值）=风险量化影响；ROI=可交付物预期回报
- 比较 EMV 与 ROI -> 决定何时何地把风险应对纳入计划工作（风险调整 ROI 曲线）

### 储备（§2.8.5.3，节 11 已讲）
- 应急储备=已识别风险（基准内，PM 可动用）
- 管理储备=未知事件（基准外，需审批）

### 口诀
威胁5（规上转减接）/ 机会5（开上分提接）/ 次生应对生·残余应对剩 / 应急已识别·管理未知

## 五、采购规划（§2.4.6）
- 采购可项目期间任何时间进行，预先规划设定期望
- 高层级范围了解后做**自制或外购分析**（make-or-buy）：定内部开发 vs 外部购买
- 结果影响**项目团队和进度计划**
- 合同三要素：货物类型 / 何时需要 / 技术规范

## 六、变更规划（§2.4.7）
- 变更来源：风险事件 / 环境变化 / 需求深入 / 客户请求
- 调整流程三选：变更控制流程（预测型）/ 重排待办优先级（适应型）/ 重定基准（重大）
- 合同项目遵循合同变更流程
- 与原则12呼应：变革管理=管人（原则12）；变更控制=管物（§2.4.7）

## 12b 易混 / 易错
- 威胁↔机会策略配对：规避-开拓 / 转移-分享 / 减轻-提高 / 接受·上报共用
- 转移 vs 减轻：责任给第三方 vs 自己降概率影响
- 开拓 vs 提高：确保发生 vs 升概率
- 次生 vs 残余：应对生 vs 应对剩
- 应急 vs 管理储备：已识别基准内 vs 未知基准外
- 变更三流程按开发方法选
- 变革管理 vs 变更控制：人 vs 物
- 采购自制或外购影响团队和进度
- 风险应对反复规划至残余与偏好相符
