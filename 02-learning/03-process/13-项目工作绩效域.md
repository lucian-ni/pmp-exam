# 第 13 节 · 项目工作绩效域
> §2.5。学完日 2026-08-17 / 掌握度 待判 / 关联错题：本节待测验。

## 定位
§2.5 项目工作绩效域 = 涉及「建立项目过程、管理实物资源、营造学习环境」的活动和功能。一句话：**把规划落成执行**——规划绩效域定"做什么/怎么做"，项目工作绩效域管"实际怎么干得高效"。与干系人/交付/测量域相互促进。

## 6 个预期成果（检查表 2-7）
1. 有效率且有效果的项目绩效
2. 适合项目与环境的项目过程
3. 干系人适当的沟通和参与
4. 有效管理实物资源
5. 对采购进行有效管理
6. 通过持续学习和过程改进提高团队能力

口诀：**效·程·沟·物·采·学**

## 一、项目过程（§2.5.1）
- 建立并**定期审查**过程（找瓶颈、看速度、查障碍）。
- **过程裁剪**：大型项目过程 > 小型；关键项目 > 不太重要（呼应原则"裁剪"）。
- 优化过程 3 方法：精益生产（价值流图测增值/非增值比，识别消除浪费）；回顾会议/经验教训；自问"下一笔资金最好花在哪"。
- 过程既**有效率**（不浪费）又**有效果**（符合质量要求/法规/标准/组织政策）。
- 过程审计 + 质量保证 = 确保过程被遵循且达成成果。
- **非增值工作**：花在跟踪过程一致性的时间不能拿去交付成果，投入够用即可。

## 二、平衡竞争性制约因素（§2.5.2）
- 制约因素：固定交付日期/法规/预算/质量政策/三重底线等；**会变化**（新需求→延进度加预算；削减预算→放质量缩范围）。
- 持续平衡 + 保持干系人满意：有时开会提备选方案并说明含义；有时在团队职权内权衡交付。

## 三、使项目团队保持专注（§2.5.3）
- PM 评估/平衡团队专注点与注意力，基于短期+长期预测。
- **聚焦生产（交付价值） vs 保护生产能力（团队健康满意度）** 两条都要，别只赶工压垮团队。
- 目的：专注交付价值 + 及时发现潜在问题/延迟/成本超支。

## 四、项目沟通和参与（§2.5.4）
- 沟通形式：正式/非正式 × 口头/书面（呼应干系人域）。
- 信息收集：会议/对话/电子存储库；按沟通计划分发。
- **特别沟通请求大量涌现 → 沟通规划不足以满足干系人 → 需干系人进一步参与**（高频考点）。

## 五、管理实物资源（§2.5.5）
- 第三方材料用品：规划/订购/运输/存储/跟踪/控制。
- 大量资源 → 集成化物流系统 + 物流计划（公司政策落地）+ 支持文档（材料类型估算/依据/用量/等级规范/交付时间地点）。
- 4 目标：减少现场搬运储存 / 消除材料等待 / 最小化报废浪费 / 促进安全环境。
- 与主进度计划整合，给各方明确期望。

## 六、处理采购事宜（§2.5.6）⭐ 重点
- 采购范围：材料/设备/用品 → 解决方案/劳动力/服务。
- **PM 通常无签合同权限**，与合同签约官/专业人士合作（高频考点）。
- 采购前制定 RFP / SOW / 条款条件 / 招标文件。
- 招标过程 = 制定公布招标文件 + 投标人会议 + 选择投标人。
- **招标文件 3 类**（易混，重点）：
  - 信息邀请书 RFI：发招标前从市场收集信息
  - 建议邀请书 RFP：复杂/繁杂范围，买方找供应商**提供解决方案**
  - 报价邀请书 RFQ：**价格是主要决定因素**，方案现成可用
  口诀：**先问市场(信息)→再求方案(建议)→终比价格(报价)**
- 投标人会议：确保所有潜在卖方对采购有清楚一致理解。
- 选择供应商标准：经验/参考/价格/及时交付，可加权。
- 签订合同：合同类型取决于采购规模/范围稳定性/风险承受力。
- 适应型+预测型混合 → 主协议 + 附录/增补（适应型变更不影响总体合同）。
- 选定供应商后更新项目计划，供应商成为干系人。

## 七、监督新工作和变更（§2.5.7）⭐ 重点
- **适应型**：新工作加进产品待办列表；**若增加的工作 ≥ 完成的工作，项目不结束**；PM 与 PO 合作管理期望；PO 持续优先级排序；进度/预算受限时高优先级交付完即可认为完成。
- **预测型**：范围基准只含已批准变更；范围变更伴随人员/资源/进度/预算变更；变更请求须附新风险评估；PM 与 CCB+请求者走变更控制流程；已批准变更整合进计划文件/待办/范围并沟通干系人。

## 八、整个项目期间的学习（§2.5.8）⭐ 重点
- 定期会议：**经验教训**（未来做得更好）+ **回顾**（即将到来的迭代改进过程）。
- 知识管理分 3 层：项目具体 / 跨项目分享 / 组织分享。
- **显性 vs 隐性知识**（高频考点）：
  - 显性：可用文字/图片/数字**编撰**（记录步骤等），用信息管理工具（手册/登记册/数据库）传递。
  - 隐性：难表达、**无法编撰**（经验/见解/实践技能），靠人际交往/访谈/**工作跟随**/论坛/研讨连接人与知识。
- 项目临时性 → 项目结束知识大量丢失 → **关注知识转移**（既提供价值，又让组织从经验获得知识）。

## 九、检查结果（§2.5.10 表 2-7）
- 有效处理变更的检查：预测法看**变更日志**是否全面评估范围/进度/预算/资源/干系人/风险影响；适应法看**待办列表**显示的完成范围比率 vs 新增范围比率。
- 采购：采购审计表明流程适当、承包商按计划。
- 实物资源：材料用量/废料/返工量表明高效利用。
