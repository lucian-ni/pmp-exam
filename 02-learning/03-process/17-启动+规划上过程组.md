# 17 · 启动 + 规划（上）过程组

> 来源：《过程组实践指南》（PMBOK7 配套）。预测型项目的过程组模型。

## 定位
第七版正文讲**绩效域**（已学完 8 个），《过程组实践指南》讲**过程组模型**——预测型项目怎么管。两套框架互补：绩效域讲"要规划哪些变量"，过程组讲"这些变量的规划过程链怎么走"。

## 五大过程组 + 49 过程分布
- 启动 2 / 规划 24 / 执行 10 / 监控 12 / 收尾 1
- **过程组 ≠ 项目阶段**：过程组是"同类活动"的分类；一个阶段里可同时发生多个过程组的活动。

## 启动过程组（2 过程）⭐
### 4.1 制定项目章程
- 正式批准项目 + 授权 PM 动用组织资源的文件。
- 三大收益：①连接项目与组织战略目标 ②建立项目正式记录 ③表明组织承诺。
- **谁编谁批**：发起人编（或 PM 与发起机构合作）；**批准人 = 发起人**；由项目以外的机构启动（发起人/PMO/项目组合治理委员会）。
- **不是合同**（未承诺金钱/交换条件）。
- **PM 任命时机**：尽早，最好制定章程时，且总在规划开始前。
- 内容关键词：项目目的、可测量目标+成功标准、高层级需求、整体项目风险、总体里程碑、预先批准财务资源、关键干系人、审批要求、退出标准、委派 PM+职责职权、发起人姓名职权。

### 4.2 识别干系人
- 定期识别干系人，分析记录：利益、参与度、相互依赖性、影响力、对项目成功的潜在影响。
- 时机：项目首现，可在章程前或同时；每阶段开始 + 重大变更时重复。
- 产出：**干系人登记册**。
- 区分：识别=搞清有谁+态度；规划干系人参与=定怎么拉他们进来；管理/监督=执行+盯。

## 规划过程组（上，13 过程）
总作用：明确范围、优化目标、定行动方案。核心词 **渐进明细**（边收集信息边细化）。

### 主线 5.1 制定项目管理计划（整合）
- 整合所有计划组件成一份综合计划。
- **基准化**：至少定范围、进度、成本三大基准。
- 基准前更新无需正式流程；**基准后只能走整体变更控制（CCB）**。

### 支线 A 范围线（5.2→5.5）
| 过程 | 产出 |
|---|---|
| 5.2 规划范围管理 | 范围管理计划 |
| 5.3 收集需求 | 需求文件 + **需求跟踪矩阵** |
| 5.4 定义范围 | 项目范围说明书 |
| 5.5 创建 WBS | **范围基准**（WBS+词典+范围说明书）|

- 需求跟踪矩阵：需求从来源追到交付。
- 章程 vs 范围说明书：章程=高层级需求+边界；范围说明书=详细范围+可交付成果+验收标准+除外责任。
- WBS 最底层 = 工作包，再拆成活动。

### 支线 B 进度线（5.6→5.10）
| 过程 | 产出 |
|---|---|
| 5.6 规划进度管理 | 进度管理计划 |
| 5.7 定义活动 | 活动清单 + 里程碑清单 |
| 5.8 排列活动顺序 | 项目进度网络图 |
| 5.9 估算活动持续时间 | 持续时间估算 |
| 5.10 制定进度计划 | **进度基准** |

- 排列顺序 PDM，4 依赖：强制/选择/外部/内部。
- 估算方法：类比/参数/三点/自下而上。
- **关键路径法 CPM**：最长路径=最短工期；关键活动**总浮动=0（或最小）**；可有**多条**关键路径。
- 进度基准 = 批准版进度模型，改动走变更控制。

### 支线 C 成本线（5.11→5.13）
| 过程 | 产出 |
|---|---|
| 5.11 规划成本管理 | 成本管理计划 |
| 5.12 估算成本 | 成本估算 |
| 5.13 制定预算 | **成本基准** |

- **成本基准 = 活动估算汇总 + 应急储备**（已识别风险）。
- **项目预算 = 成本基准 + 管理储备**（未知风险）。

## 三线串网
章程→识别干系人 → 制定项目管理计划 →（范围线+进度线+成本线）→ 三大基准 → 执行。
一句话：**范围定"做什么"、进度定"何时做"、成本定"花多少"，各自成基准汇入整合计划。**
